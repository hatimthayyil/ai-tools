# Stories

User stories for `ai`, one line each.

## Memory tree

- As a user, I should be able to rebuild any node, and everything above it is resummarised.
- As a user, I should be able to rebuild a range of memories.
- As a user, I should be able to rebuild the full memory tree.

## Output

- As a user, when I run a command over many directories, I should see a line only for each one with something to report, and one closing line that counts the rest.
- As a user, when I run a command on one directory, or the current one, I should always see what it found there, even when there is nothing to do.

## Fold

- As a user, I should be able to fold with a direction: the session being folded writes a final message aimed at it, the fold carries that message word for word, and the new session starts on the direction at once.
