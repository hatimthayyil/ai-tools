# chat/v1.rs

- Isolated v1 reader for `ai chat upgrade <name>`. Decode the stored header/column records and export serde JSON in the same tree paths.
- One new thread commit retains its v1 parent. Raw item blobs, complete source blobs and unrelated tree entries retain their object ids. The exporter does not consult live source files or rewrite earlier commits.
- A repeated upgrade writes nothing; a newer format is refused. Normal reads require v2; typed historical views require v2 snapshots, while original v1 commits remain available through Git.
- Index, item and raw sequences must be contiguous and have matching lengths before publication. Corrupt source sequences leave the v1 ref unchanged.
- Lost whitespace/newlines in v1 headers and missing original source records cannot be recovered; the exporter preserves what v1 actually stored.
