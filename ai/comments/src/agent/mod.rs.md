# agent/mod.rs

`ai agent`: an agent is a named thread. Design `ai/research/20261024T084514--agents.md`, `ai/research/20261014T002322--chat-design.md`. `model` is the harness-neutral data model; one module per harness adapter (`claude`); `store` keeps threads as JSON Lines files in `~/.ai/chat/<project id>`, `record` defines their records, `sync` binds sessions and ingests them; `rollup` plans a thread's lines (pure), `summarise` builds them (`build`, `summarise`, `Store::spawn_summariser`, `Store::config`); `view` folds a branch into the view and opens its lines, `cli` is `ai agent` and its launcher; `render` is the one item renderer of the view and the compactor. Re-exports the model, the store API and the CLI so callers write `agent::Item`, `agent::Store`.
