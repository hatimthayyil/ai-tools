# zoom.rs

Spec §7.1, for `ai memory zoom`. `n = 1`: `id|label`, original newlines kept (a bare id, as every one-message line). Else two levels down: the nodes of level `max(l-2, 0)` under it, so four `id+n/4|text` lines, or the two or four leaves for `n` of 2 or 4 (the middle level is only a compression of those, so nothing is lost and an agent needs half the zooms); with a `Meta` (the CLI) each line gets its range and fields after the id and the lines their date headers (`meta::dated`); without one: plain `id+n|text`; `None` (rendered "No line <id>.") when the node itself is not built. The CLI pages long output with `page::page` at `page::PART` (page.rs.md); every byte remains reachable.
