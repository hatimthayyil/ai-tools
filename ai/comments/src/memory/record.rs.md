# record.rs

- `Kind`: user, ai, tool, note. Spec §2 has `talk` and `echo`; here a reply is `ai` and a tool call and its result are one `tool` message. A tool message's leaf is empty (`Kind::shown`, `Message::line`): the view and compactor context skip empty lines, a merge with an empty side is the other side verbatim (no model call), zoom shows it as `HIDDEN`, `zoom id` and grep still give it whole. `note` = `ai memory note` / `import`.
- `Message`: a named-header record (`crate::record::encode`/`decode`, shared with `ai agent`): one `key value` line per non-empty field (`ts kind origin repo root head branch agent model session`, in that order; whitespace in a value becomes `_`), a blank line, then the text verbatim (newlines kept: `zoom id` returns it whole); git's commit object layout. `ts`, `kind`, `origin` are required (missing, invalid or repeated: corrupt). Other known keys absent are empty. Unknown keys are skipped: an optional field added later needs no format bump, and an older ai of the same format reading it loses nothing since records are immutable. Hand-written: header crates (mailparse, deb822, toml) bring MIME, Debian or serde machinery this does not need (research `20261013T224300`). No size limit. `ts` UTC `YYYYMMDDThhmmssZ`; no ordering key (sync is gone). `Message::new` leaves `ts` empty: the store stamps it when the message lands (store.rs.md, Time order), as it does an empty origin.
- `label`: what the tree compresses and what a free leaf holds. A note is its bare text: it has no speaker, and a `note: ` tag would be copied by every summary above it, wasting bytes at every level. Chat kinds keep `kind: text` (`user:`, `ai:`, `tool:`), since they tell speakers apart in a conversation. The kind stays stored in the header either way (`show`, `-o kind`, `grep --kind`).
- `Message.origin`: the writing store's id; empty in `Message::new`, filled by `Store::append` (a given origin is kept, so a rebuild can carry old ones).
- `Node`: one line of space-separated values under its segment's column row (store.rs.md, `Seg`); `COLUMNS` is the row this ai writes. Empty values are empty strings (two spaces in a row). `text` is the last column and alone may hold spaces, so `splitn(columns)` parses it; a new column goes before `text`. Unknown columns are skipped on decode and written empty on encode. Text is stored flattened (`flat`): every consumer shows it flattened anyway (view, zoom, compactor merge step), so a free merge is `a + " " + b` instead of the spec's `a + "\n" + b`; same byte count.
- `time_in` renders a message's UTC timestamp in a supplied zone; MCP `date` uses the machine's local zone.
- `Place.root`: the repo's first commit (prov.rs.md), set on notes only.
- `valid_ts` is public for the format-1 decoder (upgrade/v1.rs).
