# grep.rs

- ripgrep conventions (smart case, `-F`, `-i`/`-s`). Matches message text only; filters `--since`, `--kind`, `--origin`, `--agent`, `--session`, `--repo`. `-t` adds nodes (levels ≥ 1; level-0 nodes duplicate messages); `--since`, `--origin`, `--agent` and `--session` also filter nodes (by the compactor call that wrote them; free nodes have agent and session `-`), `--kind` and `--repo` exclude them.
- Message lines `id|label` under date headers like every other line (meta.rs), the label flattened and, past 400 bytes, cut to a window around the first match (`…` marks a cut). Search output, not the view: the agent zooms `id` for the whole message. The old fixed `date hh:mm origin repo kind:` prefix is gone: `--time -o origin,repo` gives it back, and the default matches `view` and `zoom`. Tree hits (`-t`) carry the range of the messages under them. The `Older:` hint repeats `--time`/`-o`. `-o` is ps's "output fields", not ripgrep's only-matching (which this grep never had).
- Order by key `(last message, n)`; newest page first within `PART_CHARS` and `-m`; `--before <id>` pages back without loss or repeats. `floor` keeps the merged page a gap-free suffix of all hits.
- `args`: the arguments as typed but `--before`, shared by the `Older:` hint (`command`, which quotes the pattern always and the rest only when needed) and the usage log (`typed`, which adds `--before`).
- `Pattern`: the pattern and its `-F`/`-i`/`-s` flags, flattened into this `Grep` and reused by `ai notes grep`, with `excerpt`.
