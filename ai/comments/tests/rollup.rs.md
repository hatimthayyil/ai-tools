# tests/rollup.rs

The roll-up compactor against real threads in temporary git repositories, with a fake backend.

- `Script` writes a Claude Code transcript entry by entry (one item each, so an entry's index is its sequence number); `at` hangs the next entry on an earlier one (a rewind). `turn` is a prompt and a 600-byte reply (never a free line); `steps(n)` n steps of a text, a Read and a 10 KB output (about 4.2 KB rendered), so 14 steps exceed the 48 KB input.
- The fake answers each call with a 300-byte line `<verb> #first..#last` from the item numbers in its `<input>`, so a line shows what it covers and two never join free; it records every task, can sleep, fail on a predicate, and records `stop`.
- Covered: free turn and node lines with no call; every level (chunks of a closed over-budget turn, its `Chunked` turn line, turn lines, nodes to level 3), each line built once, kinds, `Who`, task contents (ruler, context, part labels); a second summariser and a `build` of built keys make no call and no write; branches share the lines of their common prefix and differ after the fork; an open turn gets all but its last chunk; `build` makes the keys asked and their children only, and refuses a key that is no line; `build` returns at its deadline with the free line written and the running call stopped; a held lock makes `summarise` return `None` at once, and the log records `busy`, `built`, `end`; a failing line stays unbuilt with the node above it, and an always-failing model stops the background summariser (`OnFail::Continue`) within two waves; under `OnFail::Stop` no call starts after a failure, and the lines of the calls running beside it are kept; config defaults, overrides, a bad boolean, and `spawn_summariser` starting nothing when switched off.
- `spawn_summariser` switched on is not tested here: it would start this test binary with `chat build …` as arguments. The smoke run (summarise.rs.md) covered it with a binary that answers those arguments.
