# tests/project.rs

`ai init` as a binary with a temporary `HOME`, and `Project` through the library. Covered: `init` mints `project_` and 26 characters into a new `[project]` table and run again prints the same id and leaves the file as it was; it adds the id to a file with comments, a `[chat]` table and a `[project] name`, keeping every byte of it; a project is found from a subdirectory and named by its directory, and a nearer `ai.toml` without an id is no project; an id of another type or not a TypeID fails naming the file; the user's own file is never a project file (settings under `~/.ai` read it once, `ai chat` there says to run `ai init`, `ai init` there is refused) and `[project]` in it fails.
